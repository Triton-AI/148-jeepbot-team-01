# Hardware

## Core Components

### Power System
- 24V Lead Acid Battery
- EMO (Emergency Stop switch)
- Antispark Switch
- Power Distribution Board (PDB)

### Motor Control
- VESC (Motor Controller)
- VESC (Steering Controller)

### Compute
- Raspberry Pi 5
- Arduino (safety + relay control)

### Sensors
- 2x OAK-D Cameras
- LiDAR
- GPS Module

### Supporting Components
- DC-DC converters (24V → 12V, 5V)
- Powered USB Hub
- Wiring harness (12 AWG power lines)

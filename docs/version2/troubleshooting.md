# Troubleshooting

## Power Issues

- System not turning on:
  - Check battery voltage
  - Verify EMO is disengaged
  - Check antispark switch

- LiDAR not powering:
  - Inspect 12V DC-DC converter

## Compute Issues

- Raspberry Pi not booting:
  - Verify 5V rail output

## Motor Issues

- Motors not spinning:
  - Check VESC connections

## Wiring

- Inspect XT60 / MR60 connectors
- Check polarity

# Documentation Overview

This documentation provides a complete overview of the Jeep robot system, including hardware, software, control, and system integration.

Each section is organized to guide the reader from a high-level understanding of the system to detailed implementation and troubleshooting.

## Sections

### Overview
Provides a general introduction to the robot system, including its purpose, main components, and overall architecture.

### Current Status
Describes the current state of the project, including what is working, what is incomplete, and known issues.

### Hardware
Details all physical components of the system, including power distribution, wiring, motor controllers, sensors, and connections.

### Mechanical (Mounts)
Documents all mechanical structures and 3D-printed mounts used to hold sensors and components in place.

### Software & Control
Covers the software architecture, Raspberry Pi setup, communication with VESC controllers, and control logic.

### Setup Guide
Step-by-step instructions for setting up and running the system from scratch.

### Troubleshooting
Lists common issues, known problems, and solutions to help debug the system.

### Media
Contains images and visual documentation of the robot, components, wiring, and system setup.

### Bill of Materials (BOM)
Lists all components used in the project, including parts, specifications, and references.

### Progress & Logs
Tracks the development timeline, key milestones, and ongoing updates to the project.
